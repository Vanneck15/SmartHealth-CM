# SmartHealth CM

**SmartHealth CM** est une plateforme de santé numérique innovante, conçue spécifiquement pour le contexte camerounais. Elle offre un profil de santé digitalisé, accessible même sans connexion internet (Offline-First), permettant aux citoyens de gérer proactivement leur bien-être.

## 🌟 Fonctionnalités Principales

### 🏥 Localisation d'Hôpitaux (Mode Carte)
- Visualisation interactive des principaux centres hospitaliers au Cameroun (Yaoundé, Douala, Bafoussam, etc.).
- Accès rapide aux services d'urgence à proximité.

### 📅 Gestion des Rendez-vous
- Planification simplifiée de vos consultations médicales avec rappel intégré.
- Interface intuitive avec calendrier natif pour une précision maximale.

### 📂 Dossiers Médicaux Numériques
- Historique complet de vos consultations, diagnostics et traitements.
- Stockage local sécurisé (Room Database) pour un accès instantané sans data.

### ⏰ Rappels de Médication Intelligent
- Programmez vos prises de médicaments et recevez des **notifications système** en temps réel.
- Ne manquez plus jamais une dose grâce aux alertes automatiques.

### 🔐 Sécurité Avancée
- Authentification biométrique (Empreinte digitale/Reconnaissance faciale) pour protéger vos données sensibles.
- Design épuré "Noir sur Blanc" pour une lisibilité et un confort visuel optimal.

## 🛠 Technologies Utilisées
- **Kotlin** : Langage de programmation moderne et sécurisé.
- **Room Persistence Library** : Pour le stockage de données hors-ligne.
- **Google Maps SDK** : Pour la géolocalisation des services de santé.
- **Biometric API** : Pour la sécurité renforcée des accès.
- **AlarmManager** : Pour le système de notifications précis.

## 🚀 Installation & Utilisation
1. Clonez le dépôt.
2. Ouvrez le projet dans **Android Studio**.
3. Assurez-vous d'avoir une clé API Google Maps configurée dans le `AndroidManifest.xml`.
4. Compilez et lancez sur votre smartphone ou émulateur.
