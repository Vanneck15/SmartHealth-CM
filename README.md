Grade Calculator 
Une application simple et rapide pour calculer tes moyennes scolaires et suivre tes résultats.

* Fonctionnalités
• Ajout de notes : Enregistre tes notes avec leurs coefficients.
• Calcul automatique : Ta moyenne est mise à jour instantanément.
• Verdict : Affiche si tu as validé ou non (Admis / Échec).
• Interface claire : Utilisation facile sans réglages compliqués.

* Comment l'utiliser ?
1. Ouvre l'application.
2. Entre ta note et son coefficient.
3. Appuie sur le bouton Calculer.
4. Consulte ton résultat final en bas de l'écran.

 * Installation
1. Télécharge ou clone le projet.
2. Ouvre-le dans Android Studio.
3. Appuie sur Run pour l'installer sur ton téléphone ou émulateur.
   
 * Technologies
• Langage : Kotlin
• Interface : XML / Android Jetpack
• Stockage : Local
